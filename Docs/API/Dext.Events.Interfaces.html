API Details

record TPublishResult

Carries the result of a Publish call. HandlersInvoked counts all handlers that were started, including those that raised - use HandlersFailed to distinguish successes.
PUBLIC
function HandlersSucceeded: Integer

interface IEventHandler

Marker base interface for all event handlers. Internal - implement IEventHandler in application code.

interface IEventHandler<T>

Inherits from: IEventHandler
Typed event handler. Implement this interface to react to the event type T. Handlers are resolved via DI on each publish, allowing dependency injection.
PUBLIC
procedure Handle(const const: T)

interface IEventBehavior

Cross-cutting behavior applied around every handler invocation. Behaviors form an ordered pipeline - each must call ANext() to continue. Registered globally (all events) or per event type. Register via Services.AddEventBehavior<TBehavior>() (global) or Services.AddEventBehaviorFor<TEvent, TBehavior>() (per-event). Named Intercept (not Handle) to clearly distinguish middleware from the final IEventHandler<T>.Handle call.
PUBLIC
procedure Intercept(AEventType: PTypeInfo; const const: TValue; const const: TEventNextDelegate)

interface IEventPublisher<T>

Facade for publishing a single type of event. Follows the Interface Segregation Principle (ISP) - inject IEventPublisher<T> instead of IEventBus in components that only publish a specific type of event.
PUBLIC
function Publish(const const: T): TPublishResult
Publishes the event synchronously and waits for all handlers to process.
procedure PublishBackground(const const: T)
Publishes the event in a background thread (fire-and-forget).

interface IEventBus

The Dext Central Event Bus. Allows complete decoupling between in-memory message producers and consumers.
PUBLIC
function Dispatch(AEventType: PTypeInfo; const const: TValue): TPublishResult
Dispatches an event synchronously. Invokes all registered Handlers and Behaviors. Returns publication statistics. Raises an exception if any handler fails.
procedure DispatchBackground(AEventType: PTypeInfo; const const: TValue)
Dispatches an event asynchronously (fire-and-forget). Processing occurs in a separate thread with an isolated DI scope.

record TEventBusExtensions

Typed call-site sugar over IEventBus. Delphi E2535 prevents generic methods on interfaces, so these static helpers box the event to TValue and delegate to IEventBus.Dispatch. Defined here (not on the DI helper) to avoid the naming conflict with TEventBusDIExtensions in Dext.Events.Extensions. Usage: // FBus: IEventBus (injected) TEventBusExtensions.Publish<TOrderPlacedEvent>(FBus, Event); // or inject the narrow IEventPublisher<T> (preferred - ISP): FPublisher.Publish(Event);
PUBLIC
function Publish<T>(const const: IEventBus; const const: T): TPublishResult
procedure PublishBackground<T>(const const: IEventBus; const const: T)

class EEventDispatchException

Inherits from: EEventBusException

class EEventDispatchAggregate

Inherits from: EEventBusException
Raised by IEventBus.Publish<T> when one or more handlers raise an exception. All handlers are always invoked before this is raised. Errors contains one entry per failed handler (ClassName + Message).

type TEventNextDelegate = Type
Delegate representing the continuation in the event handling pipeline. Call ANext() to pass execution to the next behavior (or the handler). Omitting the call short-circuits the pipeline for the current handler.
