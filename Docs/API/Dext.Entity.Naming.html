interface INamingStrategy

Defines a strategy for resolving database identifiers from code identifiers.
PUBLIC
function GetTableName(const const: TClass): string
function GetColumnName(const const: TRttiProperty): string

class TDefaultNamingStrategy

Inherits from: TInterfacedObject
Default strategy: Uses class/property names as-is (PascalCase usually). TUser -> TUser UserName -> UserName
PUBLIC
function GetTableName(const const: TClass): string
function GetColumnName(const const: TRttiProperty): string

class TSnakeCaseNamingStrategy

Inherits from: TInterfacedObject
SnakeCase strategy: Converts PascalCase to snake_case. TUser -> user UserName -> user_name
PUBLIC
function GetTableName(const const: TClass): string
function GetColumnName(const const: TRttiProperty): string
PROTECTED
function ToSnakeCase(const const: string): string

class TLowerCaseNamingStrategy

Inherits from: TInterfacedObject
LowerCase strategy: Converts everything to lowercase. TUser -> tuser (or user if T prefix removed) UserName -> username
PUBLIC
function GetTableName(const const: TClass): string
function GetColumnName(const const: TRttiProperty): string

class TUppercaseNamingStrategy

Inherits from: TInterfacedObject
