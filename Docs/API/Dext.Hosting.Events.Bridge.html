class THostingLifecycleEventBridge

Inherits from: TObject
Internal service that bridges Host lifecycle notifications to the Event Bus. Inherits from TObject (not TInterfacedObject) because lifetime is managed exclusively by the DI container (stored in FSingletons as TObject). Using TInterfacedObject would cause premature destruction via ARC when temporary interface references are created during DI resolution.
