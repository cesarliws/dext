API Details

class TDextHttp2Stream

Inherits from: TObject
Represents the accumulated state for a single HTTP/2 stream. Streams are created on first HEADERS frame receipt and destroyed on close.
PUBLIC
constructor Create(AStreamId: Cardinal; AInitialWindowSize: Integer)
Creates a new stream in Idle state.
procedure Open
Transitions stream from Idle to Open upon receiving a HEADERS frame. Raises EInvalidOperation if not in Idle state.
procedure RemoteEndStream
Records that the remote peer has sent END_STREAM, closing its send side. Transitions: Open → HalfClosedRemote, HalfClosedLocal → Closed.
procedure LocalEndStream
Records that the local side has sent END_STREAM. Transitions: Open → HalfClosedLocal, HalfClosedRemote → Closed.
procedure Reset(AErrorCode: Cardinal)
Resets the stream to Closed state (RST_STREAM received or sent).
procedure AppendHeaderFragment(AData: PByte; ALen: Integer)
Appends a raw header block fragment to the internal buffer.
function FinalizeHeaders(ADecoder: THpackDecoder): Boolean
Finalizes header accumulation: decodes the buffer via HPACK. Returns False if decoding fails.
procedure AppendData(AData: PByte; ALen: Integer)
Appends DATA payload bytes to the internal data buffer.
function ConsumeSendWindow(ABytes: Integer): Boolean
Consumes ABytes from the send window. Returns False if the window would go negative (caller must not send).
procedure IncreaseSendWindow(AIncrement: Integer)
Increases the send window by AIncrement bytes (WINDOW_UPDATE received).
procedure ConsumeRecvWindow(ABytes: Integer)
Decreases the recv window as DATA is received from client.
procedure RefillRecvWindow(ABytes: Integer)
Resets the recv window (after sending WINDOW_UPDATE to client).
property StreamId:
The unique stream identifier.
property State:
Current stream lifecycle state.
property Headers:
Decoded request/response headers (available after FinalizeHeaders).
property HeadersComplete:
True when the header block has been completely received and decoded.
property DataBuffer:
Accumulated request body bytes.
property DataLen:
Valid bytes in DataBuffer.
property EndStreamReceived:
True when the client has sent END_STREAM on this stream.
property RecvWindowSize:
Current receive flow-control window size.
property SendWindowSize:
Current send flow-control window size.
property ErrorCode:
Error code set on Reset (0 = no error).

class TDextHttp2StreamMap

Inherits from: TObject
Maps stream identifiers to TDextHttp2Stream instances. Uses a sorted array for cache-friendly O(log n) lookup via binary search. Stream IDs are monotonically increasing so insertions are mostly O(1) (append to end). Max concurrent streams is bounded by SETTINGS.
PUBLIC
constructor Create(AInitialWindowSize: Integer)
destructor Destroy
function OpenStream(AStreamId: Cardinal): TDextHttp2Stream
Creates and registers a new stream with the given ID. Raises EInvalidOperation if a stream with the same ID already exists.
function Find(AStreamId: Cardinal): TDextHttp2Stream
Looks up a stream by ID. Returns nil if not found.
procedure Remove(AStreamId: Cardinal)
Removes and frees a stream by ID. Does nothing if the stream is not found.
function Count: Integer
Returns the number of currently registered streams.
function GetAt(AIndex: Integer): TDextHttp2Stream
Returns the stream at index AIndex (0-based, for iteration).
procedure SetInitialWindowSize(ASize: Integer)
Updates the initial window size for newly created streams.
procedure ApplyWindowSizeDelta(ADelta: Integer)
Applies a delta to all currently open stream send windows (RFC 9113 §6.9.2).
procedure PurgeClosed
Removes and frees all streams with State = ssClosed.
PRIVATE
function BinarySearch(AId: Cardinal): Integer
