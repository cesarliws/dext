record TRestClientRequestHelper

Record helper that extends TRestClient with the fluent Request factory. Lives in Dext.Net.RestRequest to avoid a circular unit dependency: RestRequest already imports RestClient; RestClient must not import RestRequest. Activate by adding Dext.Net.RestRequest to your uses clause. Usage: Client.Request.Post('/users').Body(Dto).Execute;
PUBLIC
function Request: TRestRequestFactory
Returns a TRestRequestFactory bound to this client instance.
