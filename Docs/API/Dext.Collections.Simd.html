API Details

class TDextSimd

Inherits from: TObject
Provides high-performance vector-accelerated operations using SIMD instructions (SSE2, SSE4.2, AVX2). Automatically falls back to pure Pascal implementations if SIMD is not supported.
PUBLIC
function IndexOfInt32(Data: Pointer; Count: Integer; Value: Integer): Integer
Finds the index of an Int32 value in a memory block using SIMD acceleration.
function IndexOfByte(Data: Pointer; Count: Integer; Value: Byte): Integer
Finds the index of a Byte value in a memory block using SIMD acceleration.
function EqualsBytes(Left: Pointer; Right: Pointer; Count: Integer): Boolean
Compares two byte buffers for equality using SIMD acceleration when available.
