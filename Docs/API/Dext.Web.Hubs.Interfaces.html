interface IClientProxy

Proxy interface for sending messages to connected clients. This is the primary interface developers use to push data. Compatible with SignalR's IClientProxy. Example: Clients.All.SendAsync('ReceiveMessage', ['Hello']);
PUBLIC
procedure SendAsync(const const: string; const const: TArray)
Sends a message to the client(s) represented by this proxy.
procedure SendAsync(const const: string)
Sends a message with no arguments.
procedure SendAsync(const const: string; const const: TValue)
Sends a message with a single argument (convenience overload).
