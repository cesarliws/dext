API Details

interface IChannel<T>

Represents a concurrent communication channel for passing data between threads.
PUBLIC
function TryWrite(const const: T): Boolean
Attempts to write an item to the channel without blocking. Returns true if successful.
function TryRead(out out: T): Boolean
Attempts to read an item from the channel without blocking. Returns true if an item was read.
procedure Write(const const: T)
Writes an item to the channel. Blocks if the channel is bounded and full.
function Read: T
Reads an item from the channel. Blocks until an item becomes available.
procedure Close
Closes the channel, preventing further writes.
function IsClosed: Boolean
Indicates whether the channel has been closed.
