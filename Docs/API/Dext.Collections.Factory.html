record TElementCategoryHelper

Classifies a type into its Code Folding category based on TypeInfo and size.
function IsManaged(Cat: TElementCategory): Boolean
Returns True if the category requires compiler-managed lifecycle (initialization, finalization, copy semantics).
function IsReference(Cat: TElementCategory): Boolean
Returns True if elements in this category are pointer-sized references (objects, interfaces). Useful for ownership management.
