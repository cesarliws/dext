Unit Dext.Collections.Memory

Global Routines

Routines
function IsManagedType(ATypeInfo: PTypeInfo): Boolean
Returns True if the given type requires compiler-managed lifecycle (initialization, finalization, copy semantics). This includes strings, interfaces, dynamic arrays, variants, and records containing any of those.
procedure RawInitialize(Dest: Pointer; Count: NativeInt; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Initializes a contiguous block of raw memory for Count elements of the given type. For managed types this calls System.InitializeArray; for unmanaged types it simply zero-fills the memory.
procedure RawFinalize(Dest: Pointer; Count: NativeInt; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Finalizes (releases) a contiguous block of raw memory for Count elements. For managed types this calls System.FinalizeArray to release ref-counted resources; for unmanaged types this is a no-op.
procedure RawCopy(Dest: Pointer; Source: Pointer; Count: NativeInt; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Copies Count elements from Source to Dest with correct managed type semantics: for managed types uses System.CopyArray (addref); for unmanaged types uses System.Move.
procedure RawMove(Dest: Pointer; Source: Pointer; Count: NativeInt; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Moves Count elements from Source to Dest, then zeros Source memory. This effectively transfers ownership of managed resources without addref/release overhead. Safe for overlapping regions if Dest < Source.
procedure RawCopyElement(Dest: Pointer; Source: Pointer; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Copies a single element from Source to Dest. Handles managed types.
procedure RawFinalizeElement(Dest: Pointer; ElementSize: NativeInt; ATypeInfo: PTypeInfo)
Finalizes a single element. For managed types releases ref-counted resources; for unmanaged types this is a no-op.
