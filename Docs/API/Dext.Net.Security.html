interface IDextTLSEngine

Core abstraction for asynchronous, memory-based TLS engine (Memory BIOs). Decouples network IO from encryption logic.
PUBLIC
function EncryptedIncoming(const const: Pointer; ACount: Integer): Integer
Processes raw encrypted incoming network data into the engine.
function PlaintextRead(const const: Pointer; ACount: Integer): Integer
Reads decrypted plaintext payload out of the engine.
function PlaintextWrite(const const: Pointer; ACount: Integer): Integer
Writes plaintext payload into the engine for encryption.
function EncryptedOutgoing(const const: Pointer; ACount: Integer): Integer
Reads encrypted outgoing network payload ready to be sent over socket.
function DoHandshake: TDextTLSEngineStatus
Drives the TLS handshake process forward.
function IsHandshakeCompleted: Boolean
Returns true if the TLS handshake has completed.
function GetNegotiatedALPN: string
Returns negotiated ALPN protocol if present (e.g. 'h2', 'http/1.1').
function GetLastIOStatus: TDextTLSIOStatus
Returns the status of the most recent TLS data operation.
function GetLastErrorCode: NativeUInt
Returns the most recent native TLS error code.
function GetPendingEncryptedBytes: NativeInt
Returns encrypted bytes waiting in the output BIO.
function Shutdown: TDextTLSIOStatus
Starts or advances the TLS close-notify handshake.
