class TDextHttp2Connection

Inherits from: TObject
Manages the complete lifecycle of a single HTTP/2 connection. Usage: conn := TDextHttp2Connection.Create(options); conn.OnRequest := procedure(c, sid, hdrs, body) begin ... end; // On each raw bytes received from socket: conn.Feed(buffer, bytesReceived); // To send a response: conn.SendResponse(streamId, responseHeaders, responseBody, True); // To close gracefully: conn.SendGoaway(HTTP2_ERR_NO_ERROR, '');
PUBLIC
constructor Create(const const: THttp2ConnectionOptions)
Creates a new HTTP/2 connection with the specified options.
destructor Destroy
Frees all resources held by this connection.
procedure Feed(AData: PByte; ALen: Integer)
Feeds raw bytes received from the socket into the connection state machine. The connection will parse complete frames, update state, fire OnRequest callbacks, and enqueue any response bytes into the output buffer. Call FlushOutput (or set OnOutput) to retrieve generated bytes.
procedure Feed(const const: TBytes; AOffset: Integer; ALen: Integer)
Convenience overload that accepts a TBytes buffer with offset.
procedure SendResponse(AStreamId: Cardinal; const const: TNameValuePairs; const const: TBytes; AEndStream: Boolean)
Sends a complete HTTP/2 response on the given stream. AHeaders must include :status at index 0. Set AEndStream=True when the response body is the final data (closes the stream). If the body exceeds MaxFrameSize it is automatically split into multiple DATA frames.
procedure SendGoaway(AErrorCode: Cardinal; const const: string)
Sends a GOAWAY frame and transitions the connection to Closing state. Existing open streams will continue until they complete or time out.
procedure SendWindowUpdate(AStreamId: Cardinal; AIncrement: Cardinal)
Sends a connection-level WINDOW_UPDATE to the peer.
function PendingOutputLen: Integer
Returns the number of pending output bytes (not yet flushed).
function ReadOutput(ABuffer: PByte; AMaxLen: Integer): Integer
Copies pending output bytes to ABuffer (up to AMaxLen) and drains the queue.
property State:
Current connection state.
property LastStreamId:
Last stream ID seen from the client (used in GOAWAY).
property OnRequest:
Fired when a complete request (all headers + all DATA) is received on a stream. The handler should call SendResponse to reply.
property OnClose:
Fired when the connection is fully closed.
property OnOutput:
Called whenever bytes are available to send to the peer. If not assigned, callers must retrieve pending output via PendingOutput. Signature: procedure(AData: PByte; ALen: Integer).

type THttp2RequestHandler = Type
Event fired when a complete HTTP/2 request is assembled on a stream. AStreamId identifies which stream the request arrived on. AHeaders contains the decoded request pseudo-headers + headers. ABody contains the full request body (may be empty for GET/HEAD).
