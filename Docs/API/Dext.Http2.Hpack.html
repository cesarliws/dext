record TNameValuePair

A name/value pair representing a single HTTP/2 header field.

record THpackDynamicTable

Encapsulates a HPACK dynamic table using a FIFO ring buffer. Entries are evicted oldest-first when the total encoded size would exceed MaxSize. Encoded size of an entry = Length(Name) + Length(Value) + 32 (RFC 7541 §4.1).
PUBLIC

Initializes the dynamic table with the given maximum size in bytes.

Inserts a new header entry at the front of the dynamic table (index 62).

Returns the entry at the given 1-based dynamic-table index (1 = newest).

Returns the number of entries currently in the dynamic table.

class THpackHuffman

Inherits from: TObject
Provides Huffman decoding for HPACK string literals (RFC 7541 Appendix B). Uses a compact FSM table (2-level, 512 states) for O(n/8) throughput.
PUBLIC
function Decode(AData: PByte; ALength: Integer): string
