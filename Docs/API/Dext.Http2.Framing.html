API Details

record THttp2Frame

Parsed representation of an HTTP/2 frame header + reference to the payload bytes. The Payload field is a direct reference into the caller's buffer - zero copy.

record THttp2Setting

A single SETTINGS parameter key/value pair.

class TDextHttp2FrameCodec

Inherits from: TObject
Provides zero-copy HTTP/2 frame parsing and type-safe write helpers. All methods are class-level - no instance needed.
PUBLIC
function TryReadFrame(ABuffer: PByte; AAvail: Integer; AMaxFrameSize: Cardinal; out out: THttp2Frame; out out: Integer): Boolean
Attempts to parse a single HTTP/2 frame from the given byte buffer. Returns False and sets ABytesConsumed to 0 if the buffer does not yet hold a complete frame (incremental - safe for stream reassembly).
function HasEndStream(const const: THttp2Frame): Boolean
Returns True if the END_STREAM flag is set in AFrame.
function HasEndHeaders(const const: THttp2Frame): Boolean
Returns True if the END_HEADERS flag is set in AFrame.
function HasAck(const const: THttp2Frame): Boolean
Returns True if the ACK flag is set (SETTINGS / PING).
function HasPadded(const const: THttp2Frame): Boolean
Returns True if the PADDED flag is set.
function GetHeaderBlockFragment(const const: THttp2Frame; out out: PByte; out out: Integer): Boolean
Extracts the HEADERS payload: strips padding and PRIORITY prefix if present. Returns a pointer and length into the original frame payload - zero copy.
function GetDataPayload(const const: THttp2Frame; out out: PByte; out out: Integer): Boolean
Extracts the DATA payload: strips the padding prefix/suffix if present. Returns a pointer and length into the original frame payload - zero copy.
function GetRstStreamError(const const: THttp2Frame; out out: Cardinal): Boolean
Parses the RST_STREAM error code from the frame payload.
function GetGoaway(const const: THttp2Frame; out out: Cardinal; out out: Cardinal; out out: TBytes): Boolean
Parses GOAWAY fields from the frame payload.
function GetWindowUpdateIncrement(const const: THttp2Frame; out out: Cardinal): Boolean
Parses the WINDOW_UPDATE increment from the frame payload.
function GetSettings(const const: THttp2Frame; out out: THttp2Settings): Boolean
Parses all SETTINGS parameters from a SETTINGS frame payload.
